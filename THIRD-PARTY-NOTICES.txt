-------------------------------------------------

3.1 Linux kernel driver drivers/platform/x86/dell/alienware-wmi-wmax.c (GPL-2.0-or-later):
    used only to confirm interface facts (WMI method ids, operation codes, thermal profile ids).
    No source code from it is included.

3.2 Keyboard LED map for the Alienware Area-51 2025, shared by a user in
    https://github.com/T-Troll/alienfx-tools/issues/588 — used as a starting point for the LED numbering;
    the map for the 16" model was then determined by tests on the hardware.
