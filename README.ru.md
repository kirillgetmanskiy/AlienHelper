# Alien Helper

[English](README.md) | **Русский**

Лёгкая замена Alienware Command Center для **Alienware 16 Area-51 (AA16250)** в духе G-Helper:
одно окно и иконка в трее, без собственных служб и фоновых агентов.

Работает через те же интерфейсы, что и AWCC:
- **ACPI WMI** `root\WMI:AWCCWmiMethodFunction`: режимы питания, Alien Mode, обороты вентиляторов, температуры, буст вентиляторов;
- **AlienFX USB HID**: подсветка клавиатуры (Darfon `0D62:1BBC`, протокол v5) и корпуса (`187C:0551`, протокол v4).

Протокол взят из [T-Troll/alienfx-tools](https://github.com/T-Troll/alienfx-tools) и Linux-драйвера
[`alienware-wmi-wmax.c`](https://github.com/torvalds/linux/blob/master/drivers/platform/x86/dell/alienware-wmi-wmax.c).

## Поддержать проект

Alien Helper бесплатный и с открытым кодом. Если программа вам пригодилась, поддержать разработку можно, купив её в
[Microsoft Store](https://apps.microsoft.com/detail/9PC5V3BMXDWP), а Store будет сам его обновлять.

## Возможности

- Режимы: Balanced, Balanced Performance, Cool, Quiet, Performance, Alien Mode. Список читается из прошивки.
  Alien Mode — игровой режим прошивки (Game Shift): максимальные лимиты мощности CPU/GPU и вентиляторы на максимум.
  У каждой кнопки режима есть подсказка с описанием.
- 4 вентилятора (2 CPU + 2 GPU): обороты в реальном времени, температуры CPU/GPU.
- Буст вентиляторов 0–100%. Он только **поднимает** обороты над кривой BIOS, 0 возвращает управление BIOS.
  Опустить обороты ниже штатных нельзя, так задумано. Буст действует только пока программа открыта:
  при выходе он сбрасывается в 0.
  Режим задаёт буст: Alien Mode ставит 100%, Cool — 75%, остальные режимы — «авто». Это срабатывает при смене режима
  в программе, в трее или снаружи (аппаратной клавишей Alien Mode) и при запуске; внутри режима ползунок можно двигать.
  Кнопка «Раздельно» (экспертный режим) даёт два ползунка: CPU (вентиляторы 0x32, 0x3B) и GPU (0x33, 0x3C).
  Режимы задают оба ползунка одинаково. Если выключить «Раздельно», всем вентиляторам ставится больший из двух бустов.
- **Custom** — отдельный режим (седьмая кнопка, меню трея, горячая клавиша режима); в каждый момент активен только один
  режим. Он работает поверх режима прошивки, выбранного в редакторе кривых («Balanced» по умолчанию), и отдаёт
  вентиляторы кривым CPU и GPU «температура → буст». Вентиляторы по режимам: Custom — строго по кривым; Alien Mode —
  100 %, ползунки заблокированы; остальные режимы — ползунки буста. Смена режима вне программы (клавиша G) завершает Custom.
- **Overclock** (внутри Custom: кнопка рядом с «Кривые…», редактор кривых или трей): смещения частоты ядра и памяти
  видеокарты NVIDIA через таблицу режимов драйвера (NVAPI), осторожными пресетами поверх смещений, которые были до этого
  (выставленных AWCC, NVIDIA App или другой программой): «Мягкий» +50 / +150 МГц, «Средний» +100 / +300, «Сильный»
  +150 / +500 (ядро / память). Прежние смещения сохраняются и возвращаются при выключении Overclock или Custom, при выходе
  из программы, при следующем запуске после сбоя и после сна. Процессор не разгоняется. При первом включении
  показывается предупреждение; горячая клавиша Ctrl+Shift+Alt+C (настраивается) переключает разгон внутри Custom. Температура сглаживается (~3 с), буст растёт до 15 %/с и снижается до 5 %/с, а в прошивку пишется не чаще
  раза в секунду на группу (изменение на 1 % — раз в 3 с). В Alien Mode вентиляторы по-прежнему на 100 %; при выключении
  Custom буст снова задаёт режим. «Кривые…» открывает редактор: по графику на группу, точки перетаскиваются (двойной
  щелчок — добавить, правый — удалить), видны текущая температура и буст. Профили: готовые «Тихий», «Сбалансированный»
  (по умолчанию), «Производительный», «Максимальное охлаждение» и свои («Сохранить», «Сохранить как…», «Удалить»,
  «Сбросить» к профилю); выбранный профиль применяется сразу.
- Яркость экрана: ползунок в главном окне (WMI `WmiMonitorBrightness`). Изменения клавишами яркости, ползунком
  Windows или из программы приходят сразу через событие `WmiMonitorBrightnessEvent`, без опроса.
- После сна или разблокировки прошивка может сама переключить режим: 40 с программа следит за ним (через 1,5, 3, 5, 10,
  20 с) и возвращает выбранный режим, а не принимает изменение (в журнале — «mode changed … after sleep/unlock»).
- Раздел **«Питание»** (по умолчанию выключен; «Настройки» → «Главное окно»): общее потребление ноутбука — на батарее
  по датчику батареи (с зарядом и оставшимся временем), от сети по счётчику платформы Intel (RAPL PSYS, MSR 0x64D, через
  PawnIO; это вся платформа, например 93 Вт при CPU 29 Вт и GPU 21 Вт); без PawnIO от сети — только CPU + GPU. **Режим Windows**: Экономия / Баланс / Максимум
  (режим питания Windows, как в «Параметры» → «Питание»).
- Подсветка: цвет и яркость отдельно для клавиатуры и для корпуса, выключение и включение из трея.
  После выхода из сна подсветка применяется заново.
- Настройки хранятся в `%APPDATA%\AlienHelper\settings.json`. Есть опция «Применять настройки при запуске».
  При включённой опции запуск возвращает последние настройки: режим питания (последний, что был активен, даже если
  его сменили аппаратной клавишей; после перезагрузки BIOS стартует в Balanced), подсветку клавиатуры (шаблон,
  анимация, цвета клавиш) и корпуса. Подсветка повторяется через 8 и 25 с после запуска, потому что служба Dell
  AlienFXSubAgent после входа в систему рисует свою, и после выхода из сна. Буст вентиляторов задаёт режим.
  Если прошивка сообщает незнакомый режим, в окне показывается «сейчас: не определён» и ни одна кнопка не выделена.
- Темы («Настройки» → «Тема»): «Тёмная» (по умолчанию), «Светлая» (тот же дизайн на светлом фоне) и «Строгая»
  (графит, квадратные углы и переключатели, плоские заливки без градиентов), «Терминал» (зелёный монохромный
  ретро-терминал: Consolas, квадратные углы, все графики в оттенках зелёного, оверлей тоже). Заголовок окна и меню в
  трее следуют теме; в остальных темах оверлей для игр и подсказка режима остаются тёмными, чтобы не слепить в играх.
- Темы из файлов: сделать тему может кто угодно (небольшой `.json` с цветами, по желанию шрифт, квадратные углы и
  оттенок для одноцветных тем) и добавить её через «Настройки» → «Тема» → «Добавить тему…»; «Сохранить текущую в
  файл…» даёт шаблон. Формат и готовые темы: [`themes/`](themes/README.md). В программу они не встроены.
- Редактор подсветки клавиш (кнопка «Клавиши» в карточке «Подсветка»): клавиатура рисуется на экране,
  ЛКМ красит клавишу (можно вести мышью), ПКМ гасит; палитра, яркость, «Залить все», «Очистить».
  Шаблоны в выпадающем списке «Шаблон» (с превью цветов): WASD, FPS, MOBA, Котик (^_^ на E-4-R, T-Y, U-8-I), Сердце, Радуга, Огонь, Океан.
  «Новый» создаёт пустой шаблон с именем, «Сохранить» записывает рисунок в выбранный свой шаблон,
  «Сохранить как…» — под новым именем, «Удалить» убирает любой шаблон (стандартные возвращает
  «Вернуть стандартные»). Несохранённые изменения отмечены точкой ● в списке.
  Огонь, Океан и Радуга анимированы (~25 кадров/с, кадр ~16 мс; у радуги поверх бегущих цветов идёт волна яркости).
  Анимация идёт в фоне и после закрытия редактора; переключатель «Анимация» её останавливает и запускает
  (активен только у анимированных шаблонов, новые анимации не создаются). Схема сохраняется
  и применяется при запуске и после сна. Выбор цвета в главном окне возвращает одноцветный режим.
  - Раскладка снята с фото клавиатуры AA16250 (основной блок + колонка Mic/Mute/Vol−/Vol+).
    Номера светодиодов: матрица 20×7 (id = ряд × 20 + позиция) по карте Area-51 2025 из alienfx-tools #588;
    отличия 16" найдены тестами на этом ноутбуке (Esc/F1–F3 = 140–143, Backspace 35, Caps 61, Shift 82/94,
    Win 103, Copilot 112, Mic 19). У широких клавиш несколько светодиодов (оба Shift двойные).
    «Залить все» проверено: горят все клавиши.
  - «Настройка раскладки»: выберите клавишу и стрелками ◀ ▶ подберите номер, пока не загорится именно она.
    Исправления хранятся в `settings.json` (`KeyIds`).
- Языки интерфейса: русский, English, Français, Español, 日本語, 中文. Выбираются в «Настройках»
  или в трее, по умолчанию берётся язык Windows. Формат чисел следует выбранному языку.
- Иконка — монограмма «AH» (`src\AlienHelper\Assets\app.ico`, генерируется `tools\make-icon.ps1`).
  Логотип Alienware — товарный знак Dell, свободной лицензии на него нет, поэтому он не используется.
- Окно «Графики» (кнопка со значком графика рядом с ⚙ вверху главного окна или пункт в трее):
  - графики в три колонки за 5 минут: температуры (CPU, GPU), обороты 4 вентиляторов,
    частоты (макс. P-ядро, E-ядро, GPU), память (RAM, VRAM), температура каждого SSD,
    операции чтения и записи в секунду каждого SSD (IOPS, счётчики Windows `PhysicalDisk`);
    во всю ширину график сети: загрузка и отдача каждого активного подключения (Мбит/с);
    у каждой видеокарты и каждого диска свои линии; если легенда не помещается рядом с заголовком, она переносится на новые строки;
  - загрузка и частота каждого из 24 ядер (P- и E-ядра отдельно, до 12 компактных плиток в ряд), из счётчиков Windows `Processor Information`.
    Счётчики работают, только пока окно графиков открыто.
  - Температура каждого ядра (значение и оранжевая линия на плитке) берётся из цифровых датчиков процессора
    (MSR 0x19C, TjMax из 0x1A2) через подписанный драйвер PawnIO. Сама программа драйвер не ставит: она использует
    PawnIO, если он есть, с модулем IntelMSR, встроенным в программу (файл IntelMSR.bin рядом с exe важнее). Только чтение;
    совпадает с Core Temp. Без PawnIO на плитках только загрузка и частота.
- Все метрики по умолчанию обновляются раз в 2 с. «Настройки» → «Обновление метрик» меняет это от 0,1 до 10 с с шагом 0,1 с;
  графики и мини-графики показывают то же время (графики 5 мин, плитки ~80 с, оверлей 2 мин), только точек больше или меньше.
  При смене частоты история начинается заново.
  Датчики читаются в отдельном потоке по ровному расписанию (отклонение около ±15 мс, замерено), поэтому занятое окно
  не задерживает и не теряет замеры; видеокарта NVIDIA опрашивается отдельно, потому что пробуждение уснувшей dGPU
  занимает ~0,5 с. Читаются только нужные метрики. Включённые разделы главного экрана читаются
  всегда, даже когда окно свёрнуто в трей (CPU — прошивка и счётчики процессора; GPU — прошивка и NVML; SSD — датчики
  дисков; сеть; режим); раздел, выключенный в «Настройках», не читается. Всё остальное — температуры ядер и источники
  только для графиков — читается, пока открыто (и не свёрнуто) окно «Графики», и графики показывают только то, что
  прочитано с момента открытия окна. Оверлей читает то, что показывает, пока он виден. Если все разделы выключены, не
  читается ничего, кроме режима питания раз в 2 с, пока включён буст вентиляторов (чтобы выход из Alien Mode клавишей G
  снимал буст). Медленные источники (≈50 счётчиков, NVML, PawnIO)
  открываются в фоне, поэтому окно сразу показывает быстрые значения (первый замер в «Графиках»: 87 мс вместо 3,4 с).
  При редком обновлении графики плавно
  сдвигаются между замерами, а не прыгают на шаг; длинная история усредняется примерно до точки на пиксель.
- Разделы главного окна (каждый можно выключить в «Настройках» → «Главное окно»; хотя бы один остаётся включённым):
  - **CPU**: модель процессора, температура, загрузка, макс. частота P/E-ядер, мощность пакета (счётчики Windows
    «Energy Meter», Intel RAPL), RAM занято/всего, вентиляторы CPU;
  - **GPU**: строка на каждую видеокарту NVIDIA (NVML): модель, температура, загрузка, частота, мощность, VRAM
    занято/всего и частота памяти; под ними вентиляторы GPU. Без NVML (например, карта AMD) одна строка показывает
    температуру GPU из AWCC. Температура VRAM берётся из датчиков NVAPI
    драйвера NVIDIA (NVML и nvidia-smi на GeForce отдают N/A; на этом ноутбуке совпадает с GPU-Z) и видна в плитке VRAM,
    на графике температур и в оверлее. Температуры RAM нет: датчик DDR5 читается только через драйвер ядра;
  - **SSD**: плитка на каждый диск, по три в ряд («SSD 1 · C:», «SSD 2» для диска без букв, модель — во всплывающей подсказке):
    температура через `IOCTL_STORAGE_QUERY_PROPERTY`, под ней IOPS чтения и записи («Ч 120 · З 45»),
    на фоне плитки график суммарных IOPS;
  - **Сеть** (по умолчанию выключена, включается в «Настройках» → «Главное окно»): плитка на каждое активное подключение
    (включено и есть шлюз; loopback, туннели и внутренние адаптеры вроде WSL не показываются), по две в ряд: скорость
    загрузки, под ней отдача и скорость канала, модель адаптера во всплывающей подсказке, на фоне общий трафик;
  - **Режим**, **Яркость экрана**, **Подсветка**;
  Если разделы не помещаются на экран (много видеокарт или дисков), окно ограничивается высотой экрана и прокручивается.
  - мини-графики за последние ~80 с: у CPU и GPU в углу плитки, у RAM и VRAM заливкой под текстом,
    у каждого вентилятора блёклой заливкой под полосой оборотов.
  «Настройки» → «Главное окно» → «Только цифры, без графиков»: только текущие значения, без мини-графиков, плитки ниже.
- Оверлей для игр: полупрозрачная панель поверх всех окон, клики проходят сквозь неё. Показывает CPU/GPU,
  частоты, мощность CPU и GPU, VRAM, RAM, вентиляторы и режим.
  - Показ: **Выкл**, **Всегда** (или горячей клавишей), **В играх** — в «Настройках» → «Оверлей» и в меню трея.
    FPS и время кадра появляются только пока впереди игра (не браузер, плеер или приложение).
  - 4 вида («Настройки» → «Оверлей» или трей): «Полный» (строки с графиками), «Мини» (столбик значений),
    «Строка» (горизонтальная полоса с мини-графиками), «Иконки» (одна строка, вместо слов нарисованные значки).
  - Перемещение: Ctrl+Shift+Alt+стрелки (можно держать). Сочетания регистрируются только пока оверлей виден.
    Положение сохраняется; выбор угла в трее сбрасывает его.
  - Показ вручную — горячей клавишей (по умолчанию `Ctrl+Shift+O`), переключателем в «Настройках» или из трея.
    Отдельный переключатель «Автоматически в играх» показывает оверлей, пока на переднем плане игра. Угол экрана
    выбирается в трее.
  - Что считается игрой: игра, которую видела сама Windows (такой список ведут Game Bar и игровой режим), или игра
    из библиотеки Steam, Epic, GOG, EA, Ubisoft или Xbox / Game Pass, в том числе в окне. Любая другая программа
    считается игрой, только пока закрывает весь экран и нагружает видеокарту, поэтому развёрнутый редактор,
    мессенджер или видео не считаются. Если программа ошиблась, откройте трей → «Оверлей», пока нужное приложение
    было последним на переднем плане, и выберите «Считать игрой» или «Не игра» (повторное нажатие возвращает
    решение детектору).
  - Игры в эксклюзивном полноэкранном режиме рисуют поверх всех окон. Чтобы видеть оверлей,
    включите в игре «оконный без рамки» (borderless).
  - FPS, время кадра (среднее и максимум) и 1% low считаются по событиям Present из ETW
    (провайдеры Microsoft-Windows-DXGI и D3D9, как в PresentMon) для процесса на переднем плане.
    ETW-сессия `AlienHelper-Frames` работает только пока виден оверлей.
    Игры на Vulkan/OpenGL без слоя DXGI могут не попасть в подсчёт.
  - Под каждым значением мини-график: FPS за минуту, столбики времени кадра (всплески выше 2× медианы — оранжевым),
    температуры, мощность, VRAM, RAM за 2 минуты.
  - «Время отклика» здесь — время кадра. Настоящую задержку ввода (как в NVIDIA Reflex) без поддержки в самой игре не измерить.
- `AlienHelper.exe --fpstest out.txt` — 6-секундный замер событий Present по процессам (только чтение).

## Запуск

`publish\AlienHelper.exe` — один файл, .NET устанавливать не нужно. Методы AWCC в WMI доступны только
администратору, поэтому сама программа работает с повышенными правами. Exe запускается без них (`asInvoker`):
- если программа уже запущена — просто показывает её окно (через именованное событие `Local\AlienHelper.Show`);
- иначе сначала объясняет, зачем нужны права (это окно можно отключить), и просит их через обычное окно UAC;
- если в UAC отказаться, программа работает в **ограниченном режиме**: то, что доступно без прав (мониторинг NVIDIA,
  загрузка процессора, сеть, графики), и кнопка **«Перезапустить с правами администратора»** в главном окне и в меню трея.

Это ветка `no-uac-bypass`: программа никогда не получает права администратора в обход окна UAC. «Автозапуск» добавляет
запись в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, и при входе Windows показывает окно UAC; задачи
Планировщика с наивысшими правами не создаются, а оставшиеся от сборок основной ветки (`AlienHelper`, `AlienHelper-NoUAC`)
удаляются при запуске (включённый автозапуск переносится в запись Run). Пакет MSIX вместо этого объявляет задачу
автозагрузки Windows (по умолчанию выключена): в настройках есть кнопка, которая открывает «Параметры > Приложения >
Автозагрузка», там её включают; при входе программа запускается и показывает одно окно UAC.

- ЛКМ по иконке в трее показывает или скрывает окно, ПКМ открывает меню (режимы, буст, подсветка, оверлей,
  язык, графики, настройки, отчёт, выход).
- Окно «Настройки» (кнопка ⚙ в главном окне или пункт в трее): разделы главного окна, оверлей и его вид, горячие клавиши,
  параметры запуска, автозапуск, язык, диагностика, «О программе».
  В «О программе» указано, на чём программа проверена (Alienware 16 Area-51, AA16250), и какие модели должны
  подойти (Alienware с AWCC 2020+; Dell G15/G16 только режимы и вентиляторы), но не проверялись.
- Горячие клавиши настраиваются в «Настройках»: показать/скрыть оверлей (по умолчанию Ctrl+Shift+O), сменить вид
  оверлея по кругу (по умолчанию Ctrl+Shift+Alt+O, скрытый оверлей при этом показывается) и смена
  режима по кругу (по умолчанию Ctrl+Shift+Alt+M, при смене внизу экрана на 1,6 с показывается название режима).
  Если сочетание занято другой программой, «Настройки» об этом сообщают.
- Закрытие окна (крестик) прячет его в трей, выход — через меню.
- `AlienHelper.exe --tray` запускает программу сразу в трее, без окна.
- Галка «Запускать свёрнутым (в трее)» (по умолчанию включена): при старте окно не открывается, только иконка
  в трее. Повторный запуск exe при работающей программе открывает окно.

### Автозапуск

Переключатель «Запускать при входе в Windows» в «Настройках» создаёт задачу Планировщика `AlienHelper`:
при входе пользователя, с наивысшими правами (без окна UAC), с параметром `--tray`, в том числе от батареи.
При выключении задача удаляется. Служб программа не ставит.

### Конфликт с AWCC

Если оставить AWCC (`AWCC.*SubAgent`, `AlienFXSubAgent`) запущенным, он может перебивать режимы
и подсветку. Можно удалить Alienware Command Center через «Приложения» или отключить его службы.
Без AWCC может перестать работать аппаратная клавиша Alien Mode, ею занимается AWCC. Режим можно
переключать из трея или горячей клавишей.

## Сборка

## Диагностика

- `AlienHelper.exe --probe out.txt` только читает и записывает в файл: ресурсы WMI, вентиляторы, датчики, режимы и устройства подсветки.
- `AlienHelper.exe --nvapi out.txt` выводит датчики температуры NVAPI видеокарт NVIDIA (только чтение, без прав администратора).
- `AlienHelper.exe --bench out.txt` замеряет время каждого источника датчиков (только чтение).
- `AlienHelper.exe --coretemps out.txt` пять раз читает температуры ядер через PawnIO (только чтение).
- `AlienHelper.exe --curvetest out.txt` прогоняет кривые на смоделированном росте температуры и показывает, что было бы записано (ничего не пишет).
- `AlienHelper.exe --curvehw out.txt` 20 с гоняет кривые на железе с профилем «Максимальное охлаждение», затем возвращает «авто».
- `AlienHelper.exe --gpuclocks out.txt` выводит таблицу частот P0 видеокарты NVIDIA (что можно менять, допустимые и текущие смещения).
- `AlienHelper.exe --octest out.txt` прогоняет цикл разгон → выключение и проверяет, что вернулись прежние смещения.
- `AlienHelper.exe --demandtest out.txt` проверяет, что читаются только нужные источники (ничего на экране — ни одного замера).
- `--screenshot` также принимает `theme=light|strict` и `numbers`.
- `AlienHelper.exe --test out.txt read profile:A0 wait:10 read boost:30 wait:10 read restore` проверяет функции по шагам.
  Шаги: `read`, `profile:<hex>`, `boost:<0-100>`, `wait:<сек>`, `kb:<RRGGBB>:<яркость>`, `ch:<RRGGBB>:<яркость>`,
  `restore` (сбрасывает буст и возвращает исходный режим). Этот режим не меняет `settings.json`.
- `AlienHelper.exe --screenshot <папка> [язык] [split] [hide=cpu,ssd,…] [fakegpus=N] [fakedisks=N] [poll=мс]` через 12 с рисует главное окно, графики, редактор клавиш,
  настройки и 4 вида оверлея в PNG. `split` показывает раздельный буст, `hide=` скрывает разделы главного окна, `fakegpus=` / `fakedisks=` добавляют фиктивные устройства для проверки раскладки, `poll=` задаёт частоту обновления. На железо ничего не пишется.

## Безопасность

Программа вызывает только те методы, которые вызывает сам AWCC: `Thermal_Information`, `Thermal_Control`
(смена режима, буст), `GameShiftStatus` (Alien Mode), `GetFanSensors`. Для видеокарт NVIDIA читаются NVML и датчики
температур NVAPI (только чтение, тот же запрос, что у GPU-Z). Прямого доступа к EC нет: BIOS продолжает
следить за температурой и вентиляторами. MUX, разгон, TCC и GPIO не трогаются.

## Установщик

```powershell
winget install JRSoftware.InnoSetup   # один раз
.\installer\build-installer.ps1
```

Результат: `installer\Output\AlienHelper-Setup-<версия>.exe` (версия берётся из `src\AlienHelper\AlienHelper.csproj`).
Установщик ставит программу в `Program Files\AlienHelper`, создаёт ярлык в меню «Пуск» (и по желанию на рабочем столе),
перед обновлением закрывает запущенную копию (`AlienHelper.exe --exit`, буст вентиляторов при этом сбрасывается).
Удаление убирает задачи планировщика `AlienHelper` и `AlienHelper-NoUAC` и спрашивает, удалить ли настройки.
Тихая установка: `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART`.

Для Microsoft Store установщик и exe должны быть подписаны сертификатом подписи кода:
`.\installer\build-installer.ps1 -SignCmd 'signtool.exe sign /fd sha256 /tr http://timestamp.digicert.com /td sha256 /a $f'`.
