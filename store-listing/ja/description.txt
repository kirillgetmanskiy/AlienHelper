名前
Alien Helper

短い説明
対応する Dell Alienware ノート PC 向けの軽量な Alienware Command Center 代替アプリ。電源モード、ファン、ライティング、モニタリングを小さなウィンドウひとつで。

説明
Alien Helper は Dell Alienware ノート PC 用のコンパクトな管理アプリです。ウィンドウひとつとトレイ アイコンだけで、独自のサービスや常駐エージェントはありません。

本アプリは対応する Dell Alienware ノート PC 専用です。Alienware 16 Area-51 (AA16250) で動作確認済み。2020 年以降の Alienware Command Center 搭載 Alienware ノート PC（m15/m17 R3–R5、x14/x15/x17、m16/m18、Alienware 16/18 Area-51、16 Aurora / 16X Aurora）で動作する見込みです。その他の PC では電源モードとファン制御は使用できません。

電源モード
• Balanced、Balanced Performance、Cool、Quiet、Performance、Alien Mode（一覧はノート PC のファームウェアから取得）。
• Custom モード: CPU と GPU のファンがそれぞれの「温度 → 回転数」カーブに従い、滑らかに加速します。
• カーブのプリセット（静音、バランス、パフォーマンス、最大冷却）と独自プロファイル。
• Custom モードの Overclock: NVIDIA GPU の控えめなオーバークロック。終了時に元のクロックへ戻します。
• モード切替のホットキーと画面表示。

ファン
• すべてのファンの回転数をリアルタイム表示。
• ファン ブーストはまとめて、または CPU と GPU を個別に。

モニタリング
• CPU、GPU、VRAM、RAM、SSD、ネットワーク、ノート PC の消費電力。
• CPU の各コアとビデオ メモリの温度（センサーがある場合）。
• 直近 5 分のグラフと、FPS を表示するゲーム内オーバーレイ。

ライティング
• キーボードと本体の色と明るさ。
• キーごとのライティング エディター、テンプレートとアニメーション（炎、海、虹）。

その他
• ダーク、ライト、シンプルのテーマと「数値のみ」モード。
• 6 言語: 日本語、英語、ロシア語、フランス語、スペイン語、中国語。
• Windows と同時に起動。

電源モードとファンの制御には管理者権限が必要です（ノート PC のファームウェアが管理者にのみ公開しているため）。

Alien Helper は独立したプロジェクトであり、Dell Technologies Inc. とは提携・承認・後援の関係はありません。Alienware、AlienFX、Alienware Command Center、Area-51 は Dell Inc. の商標で、対応ハードウェアを示すためにのみ記載しています。モード、ファンの変更やオーバークロックは自己責任で行ってください。
