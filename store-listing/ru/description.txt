НАЗВАНИЕ
Alien Helper

КРАТКОЕ ОПИСАНИЕ
Лёгкая замена Alienware Command Center для совместимых ноутбуков Dell Alienware: режимы питания, вентиляторы, подсветка и мониторинг в одном небольшом окне.

ОПИСАНИЕ
Alien Helper — компактная программа для управления ноутбуком Dell Alienware. Одно окно и иконка в трее, без собственных служб и фоновых агентов.

Приложение предназначено только для совместимых ноутбуков Dell Alienware. Проверено на Alienware 16 Area-51 (AA16250). Должно работать на ноутбуках Alienware с Alienware Command Center 2020 года и новее (m15/m17 R3–R5, x14/x15/x17, m16/m18, Alienware 16/18 Area-51, 16 Aurora / 16X Aurora). На других компьютерах управление режимами и вентиляторами недоступно.

Режимы питания
• Balanced, Balanced Performance, Cool, Quiet, Performance, Alien Mode — список берётся из прошивки ноутбука.
• Режим Custom: вентиляторы CPU и GPU следуют своим кривым «температура → обороты» с плавным разгоном.
• Готовые профили кривых («Тихий», «Сбалансированный», «Производительный», «Максимальное охлаждение») и свои.
• Overclock в режиме Custom: осторожный разгон видеокарты NVIDIA с возвратом прежних частот.
• Горячие клавиши для смены режима и подсказка на экране.

Вентиляторы
• Обороты всех вентиляторов в реальном времени.
• Буст вентиляторов одним ползунком или раздельно для CPU и GPU.

Мониторинг
• CPU, GPU, VRAM, RAM, SSD, сеть и потребление ноутбука.
• Температура каждого ядра процессора и видеопамяти (если доступны датчики).
• Окно графиков за последние 5 минут и игровой оверлей с FPS.

Подсветка
• Цвет и яркость клавиатуры и корпуса.
• Редактор подсветки каждой клавиши, шаблоны и анимации (огонь, океан, радуга).

Другое
• Тёмная, светлая и строгая темы, режим «только цифры».
• 6 языков: русский, английский, французский, испанский, японский, китайский.
• Запуск вместе с Windows.

Для управления режимами и вентиляторами нужны права администратора: прошивка ноутбука открывает их только администратору.

Alien Helper — независимый проект, не связанный с Dell Technologies Inc. и не одобренный ею. Alienware, AlienFX, Alienware Command Center и Area-51 — товарные знаки Dell Inc., они упоминаются только для указания совместимого оборудования. Изменение режимов, вентиляторов и разгон выполняются на ваш риск.

Компоненты и драйверы
• .NET 8 (MIT): https://dotnet.microsoft.com/
• System.Management, System.Diagnostics.PerformanceCounter (MIT): https://github.com/dotnet/runtime
• TraceEvent (MIT): https://github.com/microsoft/perfview
• alienfx-tools (MIT): https://github.com/T-Troll/alienfx-tools
• PawnIO IntelMSR module (LGPL-2.1): https://github.com/namazso/PawnIO.Modules
• NVML, NVAPI (драйвер NVIDIA): https://developer.nvidia.com/management-library-nvml, https://github.com/NVIDIA/nvapi
• PawnIO driver (необязательный, ставится отдельно): https://pawnio.eu/
