# Проверка AlienHelper перед публикацией в Microsoft Store

Дата: 18.10.2026. Сверено с Microsoft Store Policies 7.20. Это технический разбор, а не юридическая консультация.

## 2. Товарные знаки (Store 10.1.1, 11.2)

- ✅ Добавлен отказ от аффилиации: строка внизу окна, окно «О программе», `THIRD-PARTY-NOTICES.txt`.
- ✅ Модель в заголовке берётся из Windows (`Win32_ComputerSystem`), а не прописана в коде.
- ⚠️ **Название «AlienHelper»** созвучно Alienware. Store требует, чтобы приложение не вводило в заблуждение о связи
  с другими продуктами. Надёжнее выбрать нейтральное имя, а Alienware упоминать только в описании
  («для ноутбуков Alienware»).
- ⚠️ Название режима **«Alien Mode»** — ваша переименовка Dell G-Mode. Стоит подумать о нейтральном имени
  (например, «Max»).
- ⚠️ В описании для Store не используйте названия Alienware, AWCC и G-Mode в поисковых терминах (10.1.3).

## 3. Безопасность и установка (Store 10.2)

- ⚠️ **«Запуск без окна UAC»** (задача Планировщика с наивысшими правами) может быть расценён как обход защиты
  Windows (10.2: «не отключать платформенные функции безопасности»). Для версии в Store лучше убрать эту опцию.
  Автозапуск через такую же задачу — тот же риск.
- ⚠️ **Чистое удаление (10.2.7):** задачи Планировщика `AlienHelper` и `AlienHelper-NoUAC` и папка
  `%APPDATA%\AlienHelper` остаются после удаления exe. Установщик должен их удалять (или приложение не должно их создавать).
- ⚠️ **Подпись кода (10.2.9):** для публикации exe/msi нужен сертификат подписи кода от доверенного центра
  сертификации (Microsoft Trusted Root Program). Сейчас exe не подписан.
- ⚠️ **Тихий установщик (10.2.9):** Store принимает только .msi/.exe-установщик с тихой установкой
  (окно UAC допустимо). Сейчас программа — переносной exe без установщика. Вариант: MSIX с полным доверием
  (нужны ограниченные возможности, в том числе повышение прав; Microsoft одобряет их по запросу) или MSI.
- ✅ Программа не скачивает и не запускает код из интернета (10.2.2), не ставит службы и драйверы (10.2.4).

## 4. Совместимость (Store 10.4.1)

- ✅ При запуске на устройстве без интерфейса Alienware (AWCC WMI) показывается сообщение, программа работает
  с ограниченными функциями.
- ✅ На непроверенной модели Alienware показывается одно предупреждение.
- ⚠️ В описании для Store нужно прямо указать: «работает только на ноутбуках Alienware, проверено на
  Alienware 16 Area-51 (AA16250), требует прав администратора».

## 5. Данные и приватность (Store 10.5)

- ✅ Программа ничего не отправляет в сеть и не собирает личные данные. Названия процессов (для FPS) используются
  только на экране. Политика конфиденциальности, скорее всего, не обязательна, но Partner Center может её запросить.
  Достаточно короткого текста «приложение не собирает и не передаёт данные».

## Итог

Лицензионных препятствий нет: весь сторонний код под MIT и указан. Перед публикацией нужно:
1. сменить название (и, по желанию, «Alien Mode»);
2. для Store-версии убрать «Запуск без окна UAC» и автозапуск через задачу с наивысшими правами
   либо удалять задачи при деинсталляции;
3. сделать установщик (MSI или MSIX) и подписать его сертификатом;
4. в описании указать ограничения по оборудованию и правам администратора.
